## 요구사항 정리

주요 목표: 문자열 계산기를 구현한다.

1. 계산기는 기본 구분자(`:`, `,`)를 가진다.
2. 계산기는 커스텀 구분자를 지정할 수 있다.
    * 커스텀 구분자는 문자열 앞부분의 `//`와 `\n` 사이에 위치하는 `문자`를 커스텀 구분자로 사용한다.
    * `//.\n` -> 커스텀 구분자 = `.`
3. 분리한 각 숫자의 합을 반환한다.
4. 잘못된 입력 시 `IllegalArgumentException`이 발생한다.
    * 프로그램은 즉시 종료된다.

> 엣지 케이스 정리

**기본**
- [x] 빈 문자열(`""`)의 경우 0을 반환한다.
- [x] 양의 정수가 아니라면 입력 받을 수 없다.
   - `"0"` 입력은 받을 수 없다.
   - 음수 또한 입력받을 수 없다.
- [x] 공백(`" "`)인 경우는  잘못된 입력이다.
   * ` `라는 구분자가 생긴 꼴이다.
- [x] 구분자로 끝나는 경우는 잘못된 입력이다.
- [x] `"1, 2, 3"`과 같은 입력은 잘못된 입력이다.
  - 공백은 하나의 구분자가 될 수 있고, 이는 기본 구분자가 아니다.
- [x] 각 숫자의 20자리 이상(Long 타입 맥스 사이즈 + 1) 입력에도 정상 동작해야한다.
  * 문자열 계산기이므로 각 숫자는 매우 큰 수가 들어올 수 있다.
  
**커스텀**
- [x] `"//.-\n1"`과 `"//.\n//-\n1"`, `"a//.-\n1` 같은 입력은 받을 수 없다.
  * `//`와 `\n` 사이에 `문자들`혹은 `문자열`이 있는 꼴이다.
  * `//`와 `\n` 사이에 `문자열`이 있는 꼴이다.
  * 커스텀 구분자 입력은 `//`로 시작해야 된다.

주의 사항: 입/출력 시 제공되는 Console API를 사용한다.
